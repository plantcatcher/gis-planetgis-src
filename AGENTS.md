# AGENTS.md

## Environment
- Node: `export PATH=~/.local/node/bin:$PATH` (the `~/opt/bin/npm` shim points to a missing pnpm).
- Python 3 with pyproj / shapely / pandas / pypdf is available for the data scripts.

## Verify
- Typecheck: `npx tsgo -p tsconfig.check.json`; lint: `npx biome lint <files>`.
- Full gate: `npm run build` (runs prerender + sitemap + `check-seo`; Baidu push is skipped without env vars).

## Reference pages (地理编码速查系列)
- `content/learn/` lookup-table pages are generated by `scripts/ref_pages/*.py` — edit the script, not the `.md`, then re-run it
  (`cd scripts/ref_pages && python3 <script>.py`). Raw downloads are cached in `/tmp/geodata` (`REF_CACHE` overrides).
- Frontmatter `tableSearch: true` turns on the in-page table filter; `updated:` feeds sitemap lastmod / dateModified.
