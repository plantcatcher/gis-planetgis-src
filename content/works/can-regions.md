## 介绍

世界面积第二大国，10 个省 + 3 个地区，北方三地区占去国土近七成。这张图把加拿大的省与地区摊开在同一张地图上：**点一下任意省 / 地区，右侧直接弹出卡片**——中文名、首府、人口、面积（几何实算）与行政区类型。

地图本体是 **GADM 4.1** 的行政边界，默认按 **人口** 分级着色；顶栏可在 **人口 / 面积 / 类型** 之间切换——选「类型」则按省 / 地区分类着色。

不满足于一级？勾选左下角「普查分区」，展开 **293 个普查分区**看一级以下的行政区划。

## 功能特点

- **三个指标切换着色**：**人口 / 面积 / 类型**一键切换，颜色越深数值越大。
- **点即出卡**：选中色块变透明、透出底图，并用一圈色环勾住边界；卡片给出**中文名、首府、人口、面积与行政区类型**。
- **人口为普查口径**：采用该国最近一次人口普查 / 官方估计（约值），并注明来源年份。
- **面积实算**：每个一级区的面积由几何球面实算（约值），不依赖外部统计。
- **三种底图**：Esri 卫星影像（默认，压暗）/ 地形晕渲 / 深色无底图。
- **可展开 293 个普查分区**：普查分区边界作为可叠加图层，勾选后可点任意单元看所属省 / 地区。
- **经纬网格与分享链接**：可叠加 5° 经纬网格；选中后地址栏带上定位状态。

## 数据来源与合规

省 / 地区、普查分区边界来自 **GADM 4.1**（数据集 `gadm41_CAN_shp`，WGS84 / EPSG:4326，公开数据），坐标系与 Esri 全球影像底图对齐。中文名与首府按通行译法整理，人口为 **2022 年加拿大官方估计**（约值），面积由几何球面实算（约值），行政区类型取自 GADM 的 ENGTYPE 字段。

## 使用教程

1. 打开地图，默认停在 **人口** 着色、卫星影像底图。悬停任意区域会浮出名称与数值。
2. 顶栏点「人口 / 面积 / 类型」切换统计口径；颜色对应的具体量级在右下角图例里看。
3. **点一个省**：右侧弹出卡片，地图缩放到该单位范围并用色环勾边。卡片里直接看首府、人口、面积与类型。
4. 想看一级以下行政：勾选左下角「普查分区」，边界浮现后可点任意单元看所属省 / 地区。
5. 只想看数据不想看影像：把底图切成「深色」。
6. 想退出选中：点卡片右上角关闭按钮，或点地图空白处。

## 常见问题 FAQ

<details>
<summary>Q: 人口数据来自哪里、是哪一年？</summary>

人口来自该国最近一次**人口普查或官方估计**（约值），并在页面「数据来源」注明口径：**2022 年加拿大官方估计**（约值）。不同国家普查年份不同，故不作跨国横向比较，仅用于本图内部着色与对照。

</details>

## 一点解读

加拿大按人口着一次色，几乎整个北纬 60° 以北都是浅色——努纳武特、西北地区面积加起来超过全国三分之一，人口却不到 9 万。而安大略、魁北克、不列颠哥伦比亚三省就装下了近四分之三的加拿大人，贴着美加边境排成一条窄带。
