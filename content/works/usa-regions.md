## 介绍

50 个州 + 哥伦比亚特区，跨越北美大陆并远及太平洋。这张图把美国的州摊开在同一张地图上：**点一下任意州，右侧直接弹出卡片**——中文名、首府、人口、面积（几何实算）与行政区类型。

地图本体是 **GADM 4.1** 的行政边界，默认按 **人口** 分级着色；顶栏可在 **人口 / 面积 / 类型** 之间切换——选「类型」则区分州与联邦区。

不满足于一级？勾选左下角「县」，展开 **3148 个县**看一级以下的行政区划。

## 功能特点

- **三个指标切换着色**：**人口 / 面积 / 类型**一键切换，颜色越深数值越大。
- **点即出卡**：选中色块变透明、透出底图，并用一圈色环勾住边界；卡片给出**中文名、首府、人口、面积与行政区类型**。
- **人口为普查口径**：采用该国最近一次人口普查 / 官方估计（约值），并注明来源年份。
- **面积实算**：每个一级区的面积由几何球面实算（约值），不依赖外部统计。
- **三种底图**：Esri 卫星影像（默认，压暗）/ 地形晕渲 / 深色无底图。
- **可展开 3148 个县**：县边界作为可叠加图层，勾选后可点任意单元看所属州 / 联邦区。
- **经纬网格与分享链接**：可叠加 5° 经纬网格；选中后地址栏带上定位状态。

## 数据来源与合规

州 / 联邦区、县边界来自 **GADM 4.1**（数据集 `gadm41_USA_shp`，WGS84 / EPSG:4326，公开数据），坐标系与 Esri 全球影像底图对齐。中文名与首府按通行译法整理，人口为 **2020 年美国人口普查**（约值），面积由几何球面实算（约值），行政区类型取自 GADM 的 ENGTYPE 字段。

## 使用教程

1. 打开地图，默认停在 **人口** 着色、卫星影像底图。悬停任意区域会浮出名称与数值。
2. 顶栏点「人口 / 面积 / 类型」切换统计口径；颜色对应的具体量级在右下角图例里看。
3. **点一个州**：右侧弹出卡片，地图缩放到该单位范围并用色环勾边。卡片里直接看首府、人口、面积与类型。
4. 想看一级以下行政：勾选左下角「县」，边界浮现后可点任意单元看所属州 / 联邦区。
5. 只想看数据不想看影像：把底图切成「深色」。
6. 想退出选中：点卡片右上角关闭按钮，或点地图空白处。

## 常见问题 FAQ

<details>
<summary>Q: 人口数据来自哪里、是哪一年？</summary>

人口来自该国最近一次**人口普查或官方估计**（约值），并在页面「数据来源」注明口径：**2020 年美国人口普查**（约值）。不同国家普查年份不同，故不作跨国横向比较，仅用于本图内部着色与对照。

</details>

## 一点解读

美国的人口地图是一张「东密西疏」的图：加利福尼亚、得克萨斯、佛罗里达三州就占了全国近三成人口，东北新英格兰诸州小而密、连城成片；而阿拉斯加一个州就比得克萨斯还大，人口却不到 75 万。切到「类型」，只有首都所在的哥伦比亚特区不属于任何州。
