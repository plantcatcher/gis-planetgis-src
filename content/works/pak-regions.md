## 介绍

南亚次大陆西北的印度河之国，4 个省 + 1 个首都区 + 2 个直管区，印度河灌溉平原养活了全国绝大多数人口，喀喇昆仑公路把它与中国连在一起。这张图把巴基斯坦的省 / 直管区摊开在同一张地图上：**点一下任意省 / 直管区，右侧直接弹出卡片**——中文名、首府、人口、面积（几何实算）与行政区类型，以及一句看点。

地图本体是 **GADM 4.1** 的行政边界，默认按 **人口** 分级着色；顶栏可在 **人口 / 面积 / 类型** 之间切换——选「类型」则按行政区类型分类着色，一眼看清这个国家的结构基因。

不满足于一级？勾选左下角「专区」，展开 **32 个专区**看省 / 直管区以下的行政区划。

## 功能特点

- **三个指标切换着色**：人口用 log 尺度分级（越深越多）；面积由几何实算；选「类型」则按行政区类型分类着色。
- **点即出卡**：选中色块变透明、透出底图，并用一圈色环勾住边界；卡片显示中文名 / 首府 / 人口 / 面积 / 看点。
- **面积实算**：每个省 / 直管区的面积由几何球面实算（约值），不依赖外部统计。
- **三种底图**：Esri 卫星影像（默认，压暗）/ 地形晕渲 / 深色无底图。
- **可展开 32 个专区**：专区边界作为可叠加图层，勾选后可点任意单元看所属省 / 直管区。
- **经纬网格与分享链接**：可叠加 5° 经纬网格；选中后地址栏带上定位状态。

## 数据来源与合规

省 / 直管区、专区边界来自 **GADM 4.1**（数据集 `gadm41_PAK_shp`，WGS84 / EPSG:4326，公开数据），坐标系与 Esri 全球影像底图对齐。面积由几何球面实算（约值），行政区类型取自 GADM 的 ENGTYPE 字段；**人口、首府与中文译名为人工整理**（通行译法 + 各国统计局 / 普查近似值），仅供快速对照。本图仅展示行政边界几何，界线画法不代表任何立场。

### 关于争议地区的说明

**克什米尔地区的说明**：本数据集含 GADM 依其来源口径列入巴基斯坦的「阿扎德克什米尔」与「吉尔吉特-巴尔蒂斯坦」两个一级政区。克什米尔地区为印度与巴基斯坦之间的争议地区，本页所述「8 个一级政区」等计数均为对该数据集的客观描述，**不代表任何立场，也不构成对主权归属的判断**；涉及该地区以及涉及中国疆域的正式制图，请使用中国官方发布的标准地图数据。

## 使用教程

1. 打开地图，默认停在 **人口** 着色、卫星影像底图。悬停任意省 / 直管区会浮出名称、类型与面积。
2. 顶栏点「人口 / 面积 / 类型」切换统计口径；颜色对应的具体量级在右下角图例里看。
3. **点一个省 / 直管区**：右侧弹出卡片，地图缩放到该单位范围并用色环勾边。卡片里直接看中文名、首府、人口、面积与看点。
4. 想看省 / 直管区以下行政：勾选左下角「专区」，边界浮现后可点任意单元看所属省 / 直管区。
5. 只想看数据不想看影像：把底图切成「深色」。
6. 想退出选中：点卡片右上角关闭按钮，或点地图空白处。

## 常见问题 FAQ

<details>
<summary>Q: 人口 / 首府的数据准吗？</summary>

人口取自各国统计局 / 最近一次普查的近似值，首府为中文通行译法；面积由几何实算。三者仅供快速对照，正式用途请以各国官方发布为准。GADM 数据本身不含人口，本站的人口 / 首府为逐区人工整理。

</details>

## 一点解读

巴基斯坦 8 个一级政区按人口着色，几乎就是「一条印度河」的形状——旁遮普沿着五河平原铺开，扛下全国一半以上人口；信德省靠卡拉奇这个千万级港口城市撑起第二极；而西南的俾路支斯坦占了国土面积的四成以上，人烟却稀到几乎看不见。切到「面积」看，俾路支斯坦与开伯尔-普什图省才是真正的巨块。这个国家的地理逻辑极其直白：印度河在哪，人就在哪。
