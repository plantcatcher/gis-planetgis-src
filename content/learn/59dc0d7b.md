> 广东的姓大多指向"中原→珠玑巷"一条线；广西的姓是一部**百越土著 + 中原移民 + 粤闽迁客 + 跨境交融**的四重奏，壮族大姓硬生生插进前六，这是广西最独有的底色。

## 一、广西前十大姓（全区，约5360万人口径）

![广西](https://blogphoto.planetgis.cn/PicGo/2026-09-05-4d3e4edbbeeedc6b64be6ed569809f21-sz_88994.png)

对比广东前五大（陈、黄、李、张、林）全是中原南迁广府线；广西前五大里**韦、覃**两个壮族大姓直接挤进前三、前六——这是两省姓氏格局最醒目的分野。

![广西](https://blogphoto.planetgis.cn/PicGo/2026-09-05-4f5a6a9c60db899f7e9025438511f56a-sz_130840.png)

## 二、广西姓氏从哪来？

1. 岭南土著根（百越 / 西瓯 / 骆越 → 壮侗苗瑶）

> **广西真正的"原住民姓"，是壮、瑶、苗等民族的汉化姓。**

- 壮族姓氏的两类来历：
- 借用汉字表壮义：农（壮语 ndoeng = 森林）、莫（= 黄牛）、蓝（= 竹藤编的篮子）、甘（= 岩洞）、谭（= 水塘）、陆（= 鸟）。
- 直接受汉姓 / 峒主影响：部分壮族"峒民"随峒主改汉姓，或汉族流民、商人融入后带来姓氏。
- 基因坐实了"本土形成"：
- 广西韦氏 O-Z23762：约 311 万人（占广西 6.22%），形成、发展、壮大于广西本地，是大部分广西韦姓真正的始祖；族谱里"京兆韦氏南迁""韩信改韩为韦"等说法在基因面前多站不住脚。
- 广西覃氏 O-MF31768：约 203 万人（占广西 4.06%），覃姓全国约 71.6% 集中在广西——遇到覃姓，十有八九是广西人。
- 瑶族根姓：蓝（瑶族主姓之一）、盘（盘瓠 / 盘王信仰，唱《盘王歌》）。

![广西](https://blogphoto.planetgis.cn/PicGo/2026-09-05-32b8fa8bed1a02af1ff74b92d3cf0c6c-sz_225964.jpeg)

2. 中原—湖广移民（秦汉至今的"正统"汉姓线）

- 秦汉：秦始皇开灵渠、平岭南，驻军与移民留居，是最早进入壮区的汉姓（如南越王赵佗本为河北真定人）。
- 唐宋：随军、经商的中原百姓落籍（**李**、部分**黄**）。
- **明清"湖广填四川"：杨、刘、张等汉族大姓集中迁入，耕读传家、宗族聚落遍布桂东北桂东南。**

![广西](https://blogphoto.planetgis.cn/PicGo/2026-09-05-2449d9b0d50122c941bf07d0a01df100-sz_748927.png)

3. 粤闽迁客（沿水系与海岸进入）

- 广府人沿西江上溯：**梁、陈**的一部分，宋代从广东佛山等地入桂，在梧州、玉林开商号，留下镬耳屋建筑。
- 客家人入桂东南：陈等姓明清从闽西、粤东迁入，贺州、玉林建客家围屋，客家山歌与壮族嘹歌互鉴成"桂南调"。
- 闽南人沿海岸南下：北海、钦州、防城港一带讲"海边话 / 白话"的群体，多由福建莆田、泉州方向迁来。

![广西](https://blogphoto.planetgis.cn/PicGo/2026-09-05-539a770747fe3e0b3415d4e7c306d405-sz_324171.png)

4. 跨境交融姓（中越边境特有色）

- **阮**：越南第一大姓，也是广西东兴、凭祥等边境城市特色姓，多为中越边民通婚融合；族人既说粤语也讲越南语，宗祠对联兼用汉字与越南喃字。
- **侬**（农分支）、京族姓氏等，进一步印证中越边境文化亲缘。

![广西](https://blogphoto.planetgis.cn/PicGo/2026-09-05-2a1cb4ec58d31bb2ed6abb45dfb986ab-sz_697215.png)

## 三、广西 vs 广东：姓氏格局对照

![广西](https://blogphoto.planetgis.cn/PicGo/2026-09-05-38e058004e97678c3ac9850905aed4a0-sz_26949.png)

![广西](https://blogphoto.planetgis.cn/PicGo/2026-09-05-f026d6f0d8e353f20721b1cce1550f0f-sz_348830.jpeg)

核心差异：广西的"第一大姓"黄，同时是壮族和汉族的通用大姓；广东没有哪个姓像韦、覃那样，根深深扎在百越土著里却人口碾压。

## 四、冷知识

![广西](https://blogphoto.planetgis.cn/PicGo/2026-09-05-c24505970e226769c4635eb86e8ad80f-sz_407473.jpeg)

- 韦姓的"蛙神"：南宁韦氏宗祠有用古壮字写的族谱；来宾韦氏保留"蚂拐节"（祭蛙神，国家级非遗）。
- 黄姓的"密码诗"：海内外黄氏通用**"峭山公认祖诗"**（外八句/内八句），背得出即可认祖归宗，是宗族主义的文化符号。
- 地名即姓氏：贵港"覃塘"因覃姓聚居得名；壮语"那"= 稻田，"那文化"由农姓等稻作族群延续。
- 遇覃遇韦，猜广西：这两个姓的广西浓度高到可以"无脑猜"。
