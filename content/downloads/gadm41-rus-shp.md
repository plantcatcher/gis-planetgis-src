> 本数据集为 GADM（Global Administrative Areas）v4.1 的**俄罗斯**部分，四级 Shapefile 共 20 个文件，压缩包仅约 **39.4 MB（39,408,514 字节）**——世界国土面积第一的国家，数据反而比德国还轻，因为全包几何做了较强简化。一级为 83 个联邦主体（GADM 口径），从东欧平原到楚科奇的 170 个经度一次铺开，做欧亚大陆尺度的分析非常顺手。本文所有数字均经 Python geopandas 逐要素实算，非官方文档转述。



## 数据内容

包内按行政层级分为 4 个独立 Shapefile（每级均含 `.shp / .shx / .dbf / .prj / .cpg`）：

- **Level 0（国界）**：1 个要素，俄罗斯全国边界。字段 `GID_0`（RUS）、`COUNTRY`。
- **Level 1（联邦主体）**：**83 个要素**，按 `ENGTYPE_1` 实算：Region（州 / 州级区）46、Republic（共和国）21、Territory（边疆区）9、Autonomous Province（自治州 / 自治专区）4、City（联邦直辖市：莫斯科、圣彼得堡）2、Autonomous Region（自治区，犹太自治州）1。字段含 `NAME_1`、`VARNAME_1`、`ISO_1`、`HASC_1`、`CC_1` 等 12 个。
- **Level 2**：**2445 个要素**，行政区 / 市一级（rayon / city district 等）。
- **Level 3**：**2562 个要素**，更细的市镇一级单元。

各层级通过 `GID_0 → GID_1 → GID_2 → GID_3` 编码严格逐级嵌套（如 `RUS.1.2.1_1`），字段含各级 `NAME_x / VARNAME_x / TYPE_x / ENGTYPE_x / HASC_x`。

## 坐标系与格式

- 坐标系：**GCS_WGS_1984（EPSG:4326，WGS84 经纬度）**，`.prj` 随包附带。
- 文本编码：`.cpg` 指定 **UTF-8**，属性表英文存储，无乱码。
- 几何类型：POLYGON（MultiPolygon）。范围经度 -180°—180°（**东端楚科奇跨 180° 经线**）、纬度 41.19°N—81.86°N，全国轮廓面积约 **1692.6 万 km²**（EPSG:6933 等面积投影实算），居世界第一。

## 使用方法

1. **QGIS / ArcGIS**：解压后直接「添加矢量图层」加载 `.shp`；做俄罗斯专题图通常选 L1（83 个联邦主体），高纬度地区建议换等面积 / 等角圆锥投影渲染，墨卡托下西伯利亚会被过度放大。
2. **Python 空间分析**：`geopandas.read_file("gadm41_RUS_1.shp")`；`sjoin` 挂载油气田 / 铁路点数据，`dissolve(by="ENGTYPE_1")` 可按联邦主体类型分组统计。
3. **WebGIS**：`ogr2ogr` / `tippecanoe` 转 GeoJSON / MBTiles 接入 MapLibre / Leaflet；跨 180° 经线的数据做自定义渲染时注意坐标平移处理。

## 已知数据瑕疵（实测发现，重要）

- **联邦主体数量为 83（GADM 口径）**，与俄官方现行「89 个联邦主体」的宣称口径不一致：GADM 4.1 未将 2014 年以来俄方单方面宣布并入的克里米亚、塞瓦斯托波尔等地区计入俄罗斯（其数据集中这些单元仍按乌克兰原属行政区划归并）。本包为**原始未删改副本**，该画法不代表也不改变中国政府的立场，做正式涉界制图请以自然资源部标准地图服务发布的官方数据为准。
- **楚科奇自治区等东端要素横跨 180° 经线**，全包经度范围 -180°—180°；用简单 bbox 判断会误以为数据横跨整个世界，QGIS / ArcGIS / geopandas 正常读取即可，自定义渲染需做跨经线平移。
- 全包几何简化程度较高（压缩包仅 39.4 MB），远东破碎海岸线的细节有明显取舍，做海岸线精细研究需另寻更高精度数据源。
