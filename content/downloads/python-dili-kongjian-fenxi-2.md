> 《Python地理空间分析指南（第2版）》原著名 *Learning Geospatial Analysis with Python, Second Edition*，由**Joel Lawhead（莱哈德）著，邓世超译**，经 Packt Publishing 授权、**人民邮电出版社**于**2017年4月**出版，**ISBN 978-7-115-44821-7**，定价79.00元，开本24cm，全书317页，CIP 数据核字(2017)第039802号。

本书以地理空间分析为背景，介绍一批在特定领域流行且实用的技术，重点是充分利用 Python 语言和框架的强大功能高效开展地理空间分析。书中尽量使用原生 Python 代码以减少依赖，并随书提供完全使用 Python 3 编写的源码，是目前市面上少有的只使用 Python 3 的地理空间类图书。

## 本书的突出特点

- **纯 Python 3 实现**：全部示例基于 Python 3，避开 Python 2 的历史包袱，可直接用于当前项目。
- **覆盖地理空间全栈**：从数据格式、GIS 构建、遥感、高程数据到高级建模与实时数据，形成完整知识链。
- **重实战轻依赖**：在示例中大量使用第三方库的同时，尽量用原生代码演示，便于理解与二次开发。
- **案例导向**：NDVI 植被指数、洪水淹没模型、LIDAR 生成 TIN、影像分类等案例即学即用。

## 适用读者

本书适合希望了解测绘数字化与地理空间分析的读者，也适合使用 Python 进行空间地理分析、建模和 GIS 分析的开发人员及研究人员参考阅读；需要一定的 Python 基础。

## 全书目录

1. **第1章 Python与地理空间分析** — 地理空间分析在实际生活中的应用，GIS 与遥感的区别
2. **第2章 地理空间数据** — 主流与流行的数据格式，数据准备难点
3. **第3章 地理空间技术概览** — 地理空间软件生态与核心软件包层次结构
4. **第4章 Python的地理空间分析工具** — 用 Python 做 GIS 脚本、胶水语言与全能编程
5. **第5章 Python与地理信息系统**
   - 5.6 边框查询
   - 5.7 空间信息可视化（点密度计算 / 等值区域图）
   - 5.8 使用电子表格
   - 5.9 使用 GPS 数据
   - 5.10 地理化编码
6. **第6章 Python与遥感**
   - 6.1 图像波段变换
   - 6.2 创建直方图 / 直方图均衡化
   - 6.3 图像剪裁
   - 6.4 图像分类
   - 6.5 图像特征提取
   - 6.6 变化监测
7. **第7章 Python与高程数据**
   - 7.1 ASCII 网格文件（读取 / 写入 grids）
   - 7.2 创建地形阴影
   - 7.3 创建等高线
   - 7.4 使用 LIDAR（创建网格 / PIL 可视化 / 不规则三角网络 TIN）
8. **第8章 Python与地理空间高级建模**
   - 8.1 归一化植被指数（NDVI）应用（框架 / 载入 / 栅格化 Shapefile / 波段剪裁 / NDVI 分类）
   - 8.2 创建洪水淹没模型
9. **第9章 实时数据** — 互联网分钟级更新如何改变地理空间分析方式
10. **第10章 综合应用** — 地理空间分析技术的综合实战
