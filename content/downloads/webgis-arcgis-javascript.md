> 《Web GIS从基础到开发实践：基于ArcGIS API for JavaScript》由**刘光、曾敬文、曾庆丰 编著**，属地理信息系统软件开发方向教材，由**清华大学出版社**于**2015年3月**出版，**ISBN 978-7-302-38896-8**，字数826千字，2015年3月第1版第1次印刷，定价79.00元，封面贴有清华大学出版社防伪标签。

本书以 ArcGIS API for JavaScript 为主线，面向希望系统掌握 Web GIS 前端开发的读者。全书从基础概念讲到工程实战，既讲清地图服务的发布与调用原理，也通过大量实例演示图层控制、空间查询分析、专题图绘制、打印编辑以及与 HTML5 新特性的集成，帮助读者真正具备独立开发 Web GIS 应用的能力。

## 本书的突出特点

- **以 ArcGIS 平台为轴心**：紧扣 ArcGIS API for JavaScript，覆盖地图、图层、符号、任务类与编辑等核心 API。
- **Dojo 基础扎实**：专章讲解 Dojo 布局小部件与扩展机制，扫清前端框架门槛。
- **查询分析一体化**：系统演示 IdentifyTask、QueryTask、FindTask、RouteTask、ClosestFacilityTask 等任务类，实现空间与属性双向查询。
- **拥抱 HTML5**：第11章集成 Geolocation、WebSocket、WebGL，体现现代 Web GIS 的发展方向。

## 适用读者

本书适合地理信息系统、遥感、城市规划、资源管理等相关专业的高年级本科生与研究生，也适合政府部门与企业的 GIS 研发人员、希望从事 Web GIS 软件开发的前端工程师作为教材或参考书。

## 全书目录

1. **第1章 GIS及Web GIS概述** — GIS 发展趋势、OGC Web 服务规范、ArcGIS Server
2. **第2章 ArcGIS API for JavaScript入门** — 最简实例、API 构成、Dojo 基础、开发与调试工具
3. **第3章 页面布局** — Dojo 布局小部件、扩展小部件类管理页面元素
4. **第4章 地图与图层** — 地图类、图层控制、地图操作、自定义图层
5. **第5章 空间参考与几何对象** — 空间参考系统及转换、绘制各种几何对象
6. **第6章 符号与图形** — 与符号相关的类、要素符号化后的图形类
7. **第7章 要素图层与专题图** — 要素图层、渲染器绘制专题图（直方图 / 饼图）、CSS 样式化
8. **第8章 任务类：查询与分析** — IdentifyTask、QueryTask、FindTask、RouteTask、ClosestFacilityTask、ImageServiceIdentifyTask
9. **第9章 地图打印、仪表盘、时间滑块与编辑** — 打印 / 仪表盘 / 时间滑块、编辑小部件与工具条
10. **第10章 混搭式地图应用** — 综合创建 Mashup 地图应用
11. **第11章 Web GIS与HTML5集成** — Geolocation、WebSocket、WebGL
