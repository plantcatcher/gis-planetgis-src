> 《Python 编程：从入门到实践》（原书名 *Python Crash Course, A Hands-On, Project-Based Introduction to Programming*）由**〔美〕Eric Matthes** 著、**袁国忠** 译，**人民邮电出版社 2016 年 7 月第 1 版第 1 次印刷**（ISBN **978-7-115-42802-8**，800×1000 1/16，**29.75 印张**，**703 千字**，定价 **89.00 元**），列入"**图灵程序设计丛书**"。原书英文版由 No Starch Press 出版，作者 Eric Matthes 是阿拉斯加的一名高中科学与数学老师，从 5 岁起就一直在编写程序，本书源自他在当地讲授的 Python 入门课程。

本书是一本针对所有层次 Python 读者而作的 Python 入门书。全书分两部分：第一部分介绍用 Python 编程所必须了解的基本概念，包括 matplotlib、NumPy 和 Pygal 等强大的 Python 库和工具介绍，以及列表、字典、if 语句、类、文件与异常、代码测试等内容；第二部分将理论付诸实践，讲解如何开发三个项目，包括简单的 Python 2D 游戏开发（如《外星人入侵》）、如何利用数据生成交互式的信息图（数据可视化实战），以及创建和定制简单的 Web 应用（Django 入门），并帮助读者解决常见编程问题和困惑。

## 全书目录

**第一部分 基础篇**

- **第 1 章** 起步
- **第 2 章** 变量和简单数据类型
- **第 3 章** 列表简介
- **第 4 章** 操作列表
- **第 5 章** if 语句
- **第 6 章** 字典
- **第 7 章** 用户输入和 while 循环
- **第 8 章** 函数
- **第 9 章** 类
- **第 10 章** 文件和异常
- **第 11 章** 测试代码

**第二部分 项目篇**

- **项目 1** 外星人入侵
  - 安装 Pygame
  - 开始游戏项目
  - 添加飞船图像
  - 让飞船可移动
  - 外星人
  - 计分与等级
- **项目 2** 数据可视化
  - 生成数据（matplotlib、Pygal）
  - 下载数据
  - API 使用
- **项目 3** Web 应用程序
  - Django 入门
  - 用户账户
  - 样式与部署

**附录** 安装 Python、文本编辑器、寻求帮助、Git 与 GitHub 入门

## 本书的突出特点

- **入门到实战一气呵成**：前半部分打基础，后半部分通过三个项目让读者真正"做出东西"。
- **覆盖三大热门方向**：游戏开发（Pygame）、数据可视化（matplotlib/Pygal）、Web 应用（Django）。
- **教学经验沉淀**：作者是高中老师，讲授 Python 入门课多年，写作风格平实、可读性极高。
- **生态完整**：被翻译为多国语言，是中文世界最受欢迎的 Python 入门书之一。

## 适用读者

本书适合**上至有编程基础的程序员、下至 10 岁少年所有想入门 Python 的读者**，目标是把读者带到"可以开发实际项目"的水平。无需任何编程基础。
