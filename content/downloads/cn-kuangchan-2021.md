> 本数据集为**全国矿产地分布（2021版）**矢量数据，以 Shapefile 形式提供，共 **228,189 条**矿产地记录（有效坐标点位 **228,188 处**，Point 要素）。坐标系为 **GCS_WGS_1984（WGS84，EPSG:4326 经纬度）**，属性含矿产地名称、矿种、矿床规模、利用现状、地质工作程度、矿床成因、交通位置等字段，可直接用于 QGIS / ArcGIS / Python 矿产资源分布与成矿规律分析。**第三方整理的公开资料，未标注官方审图号**。

在浏览器里直接查看分布：打开 [全国矿产分布互动地图](/maps/cn-kuangchan-2021)，可按矿种大类 / 规模 / 利用现状 / 省市筛选、按名称搜索、散点与热力双视图，点选查看每处矿产地的详情。不想装 GIS 软件，先看互动地图就够了。

## 数据内容

压缩包内包含同一数据集的三种形态，按需取用：

- **全国矿产地分布_2021版.shp（Point，228,189 条）**：矢量点要素，属性表字段：
  - `OBJECTID` / `序号`：记录编号；
  - `矿产地`：矿产地名称（部分记录为空）；
  - `Longitude` / `Latitude`：经纬度（WGS84）；
  - `交通位置`：矿区对外交通描述（部分为空）；
  - `利用现状`：生产 / 开采 / 未利用 / 闭坑 / 在建 / 停采等原始表述；
  - `地质工作程度`：勘探 / 详查 / 普查 / 预查 / 调查等；
  - `矿床成因`：热液矿床 / 沉积矿床 / 岩浆矿床 / 砂矿床等；
  - `矿种`：以顿号分隔的矿种列表（如「锡矿、铌矿、钽矿」），共 458 个细分类目；
  - `规模`：超大型 / 特大型 / 大型 / 中型 / 小型 / 矿点 / 矿化点等。
- **全国矿产地分布（2021版）.csv（26 MB）**：原始名录表格，字段与 SHP 属性表一致，方便直接用 Excel / pandas 处理。
- 其余为 Shapefile 附属文件（.dbf / .shx / .prj / .cpg / .sbn / .sbx / 元数据 .xml）。

规模分布参考：超大型 46 处、特大型 581 处、大型 12,102 处、中型 20,103 处、小型 108,295 处、矿点 20,990 处、矿化点 6,846 处、未标注 59,225 处；利用现状中「正在开采」约 10.7 万处。

## 坐标系与格式

坐标系为 **WGS84 地理坐标系（EPSG:4326，经纬度）**，`.prj` 已随包附带，主流 GIS 软件可直接识别；叠加天地图 / OSM 底图无需纠偏，叠加高德 / 腾讯底图需注意 GCJ-02 偏移（约 100—700 米）。

## 使用方法

1. **QGIS / ArcGIS**：直接「添加矢量图层」选择 .shp 即可加载，按 `矿种` 分类设色、按 `规模` 分级符号化，即可快速复现本站的互动地图效果。
2. **Python 空间分析**：用 `geopandas.read_file()` 读取，与行政区划面做空间连接（Spatial Join）统计各省矿产资源数量，或用 `folium` / `keplergl` 出交互图。
3. **Excel / pandas**：直接打开 CSV 做透视统计——按矿种、规模、省份透视都是一行代码的事。

## 使用须知

- 本数据为公开版名录的第三方整理成果，**未标注官方审图号**；矿种、规模、坐标等属性沿用原始表，点位精度约为乡镇—村庄级，**不能当作矿区边界、井口坐标或储量依据使用**。
- 正式勘查、储量核算、矿业权与规划业务，请以自然资源主管部门发布的权威数据与最新标准地图为准。
- 台湾省、香港、澳门及南海诸岛海域矿产在本名录中基本无记录，属数据源覆盖范围所限。
- 数据仅供学习、科研与教学制图参考；商业用途请自行核实数据版权与使用授权。
