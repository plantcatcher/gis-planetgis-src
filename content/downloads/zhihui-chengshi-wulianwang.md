> 《智慧城市中的物联网技术》由**秦志光 主编，丁熠、王瑞锦、曹晟 编著**，属"信息与通信创新学术专著·智慧城市系列"，由**人民邮电出版社**于**2015年2月**出版，**ISBN 978-7-115-37301-4**，印张16，字数313千字，2015年2月第1版第1次印刷，定价75.00元。

本书把物联网技术作为智慧城市的"神经末梢"来讲解，强调以通俗易懂的语言把基本原理呈现给读者。全书共分9章，按"从应用到理论"的思路组织：先以具体案例展示物联网在智慧城市中的典型应用，再回到传感器、RFID、无线传感器网络与物联网安全等理论基础，帮助读者既见树木也见森林。

## 本书的突出特点

- **案例驱动**：智能电网、智能家居、智慧制造、食品产业链、智慧农业、智慧物流、智慧环保、智慧城管、智慧交通等案例贯穿应用篇。
- **应用与理论并重**：前4章看应用，后5章讲原理，符合"从应用到理论"的认知路径。
- **安全专题独立成章**：第9章专讲物联网感知层、网络层、应用层与传感网的多层次安全。
- **作者实战背景强**：编著者均参与过多个城市的智慧城市顶层规划与国家级试点申报，内容贴近真实工程。

## 适用读者

本书适合智慧城市相关领域的政府管理人员、规划与建设从业者，以及高校计算机、通信、自动化等相关专业师生阅读；也适合希望系统了解物联网技术体系及其在智慧城市中落地的技术人员作为入门参考书。

## 全书目录

1. **第1章 智慧城市概述** — 智慧城市的基本知识
2. **第2章 基于物联网的若干新兴产业** — 智能电网、智能家居、智慧制造
3. **第3章 基于物联网的传统产业改造** — 食品产业链、智慧农业、智慧物流
4. **第4章 基于物联网的城市基础能力提升** — 智慧环保、智慧城管、智慧交通

   - 5.3 应用体系的作用
6. **第6章 传感器技术**
   - 6.1 概念与发展
   - 6.2 传感器技术
   - 6.3 主要类型
   - 6.4 理论技术基础（组成 / 静态特性 / 动态特性）
   - 6.5 应用
7. **第7章 RFID技术**
   - 7.1 历史与现状
   - 7.2 技术分析（系统组成 / 工作原理 / 关键技术 / 测试架构 / 标准）
   - 7.3 RFID 与物联网
8. **第8章 无线传感器网络技术**
   - 8.1 概述（结构 / 特点 / 体系结构 / 分层网络）
   - 8.2 关键技术与性能指标
   - 8.3 研究及发展（国外 / 国内）
   - 8.4 应用
9. **第9章 物联网安全**
   - 9.1 概述（特征 / 威胁 / 安全特性 / 安全体系）
   - 9.2 感知层安全（密钥管理 / 鉴别 / 安全路由 / 访问控制 / 数据融合）
   - 9.3 网络层安全（IPSec / 防火墙 / 隧道服务 / 数字签名 / 身份识别）
   - 9.4 应用层安全
   - 9.5 传感网安全
