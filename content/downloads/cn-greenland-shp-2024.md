> 本数据包是从 **OpenStreetMap（OSM）** 提取的中国**绿地与休闲用地**矢量数据，压缩包内仅一个图层（文件名 `greenland.shp`，命名源自提取时的临时标识，数据范围为**中国全境**而非格陵兰）。含 **187,840 个面要素（Polygon）**，几何类型 Polygon，坐标系 **GCS_WGS_1984（EPSG:4326 经纬度）**，属性表含 `osm_id / code / fclass / name` 四个字段。压缩包约 **28.7 MB**，解压后约 **75 MB**。本文数字均由 Python 直接读取压缩包内文件头、属性表与几何实算。

## 数据内容

单一 Shapefile，包内 8 个文件（`.shp / .shx / .dbf / .prj / .cpg / .sbn / .sbx / .xml`）：

- **要素数**：187,840 个面要素（含约 4.9 万个无 `fclass` 标注的碎面）。
- **顶点总数**：2,154,203 个（体量较大，Web 端需简化后使用，见下文）。
- **范围**：经度 **73.88°—134.76°**、纬度 **15.78°—53.49°**，覆盖中国全境。
- **投影总面积**：约 **12,250 km²**（≈ 1.23 万 km²，按球面几何实算，已扣除孔洞）。
- **最大单体**：约 **644.6 km²**（个别大型森林公园 / 风景区）。

- **体育球场（pitch）**：84,657 个

## 属性字段说明

- **osm_id**（字符，12 位）：OpenStreetMap 要素 ID，可与 OSM 数据回查。
- **code**（数值，4 位）：OSM 要素的内部编码。
- **fclass**（字符，28 位）：绿地 / 休闲用地的类别，取值见上文「类型构成」。
- **name**（字符，100 位）：名称（UTF-8 编码；约 4.9 万个面为空）。

## 坐标系与格式

- 坐标系：**GCS_WGS_1984（EPSG:4326）**，`.prj` 随包附带。
- 文本编码：**UTF-8**（`.cpg` 随包附带，中文名称不乱码）。
- 几何类型：Polygon（shapeType=5），坐标单位度。属性表**不含** `Shape_Length` / `Shape_Area`，面积需自行计算。

## 数据来源与处理方式

数据提取自 **OpenStreetMap（ODbL 许可）**，筛选 `leisure=*`、`tourism=*` 及少量相关 `landuse` 标签的绿地 / 休闲用地面要素，裁剪至中国范围后导出为单一 Shapefile（2024 年基准）。由此产生的特性：

1. **绿地是碎面集合**：公园被切成边界多边形，但球场、游乐场等小面数量极多（仅 `pitch` 就 8.4 万个），「要素数」远大于「绿地个数」。
2. **属性轻量**：只有四类字段，没有面积、等级等衍生属性，需自行按几何计算。
3. **区域完整度不均**：东部与城市密集区标注完整，西部偏远地区可能缺漏——这是 OSM 众包数据的固有特征。

## 使用方法

1. **QGIS / ArcGIS**：解压后直接加载；18.8 万面在桌面端可正常渲染，按 `fclass` 分类着色即可看分布。
2. **Python 空间分析**：`geopandas.read_file()` → 按 `fclass` 筛选（如只看 `park`）→ 投影到等面积坐标系（全国可用 EPSG:4549 或 EPSG:4490 配面积量算）算绿地面积与密度。
3. **WebGIS**：体量偏大，建议先按 33 m 左右容差 Douglas-Peucker 简化、滤除碎面后再转 GeoJSON / MBTiles 接入前端地图（本站互动地图即采用此思路，保留约 6.9 万面）。

## 已知数据瑕疵（实测发现，重要）

- **顶点量巨大**：全量 215 万个顶点，直接转 GeoJSON 会有 50 MB+，前端加载吃力。**做 Web 展示务必先简化**，不要原样塞进浏览器。
- **与国内底图叠加需先转坐标**：数据是 WGS84；高德 / 腾讯底图为 GCJ-02（火星坐标），百度为 BD-09，全国范围系统性偏移约 100—700 m，直接叠加会错位，需先做坐标转换（本站互动地图已在加载时自动转 GCJ-02，无需处理）。天地图用 CGCS2000，与 WGS84 基本一致，可直接叠加。
- **约 4.9 万个面无类别 / 名称**：OSM 里只画了边界没填标签，分析时按「未标注」单独归类。
- **OSM 完整度不均**：城市与东部密、西部与偏远地区疏，做全国统计请注意采样偏差。
