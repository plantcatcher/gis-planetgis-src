怎么玩

  1. 每天系统给一座城市 / 地点：点地图任意处放下 📍 到你认为的真实位置。
  2. 放下后标记点下方会出现「📍 标定这里」，点它即结算。
  3. 标记针可拖动微调；拖动空白处是移动地图（缩放用滚轮 / 双指 / 右下角控件）。
  4. 结算后地图上会画出猜测点到真实点的距离线，并标出偏差公里数。离得越近分越高（满分 1000）。
  5. 连续完成每日挑战累加连击，断一天归零；题目由日期决定，全网同一天同题。点「下一题」进入练习局，不计连击。点顶栏「连击」可看连击日历；漏答一天还能用每周一次的「补签」把连击接上。
  6. 题型：除城市外，还会出现自然地貌（沙漠、火山、峡湾、瀑布等）与名胜古迹；题目卡会标出类型与难度（入门 / 进阶 / 冷门）。
  7. 挑战模式：5 题连答，每题 60 秒，按 5 题累计总分评级（满分 5000），适合一次玩个痛快。
  8. 分享与对战：分享会生成一张带二维码的成绩卡；挑战结束后可复制「同题对战链接」，链接里带着你的分数，好友打开就是同一组题，答完直接比高低。
