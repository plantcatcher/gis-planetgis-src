美国周边地震地图

图上画的是 1900 年以来美国及周边 8 032 次 M5.0 以上地震的震中，数据来自美国地质调查局 ANSS 综合地震目录。拖动下方年份时间轴，看这些点一年年长出来；勾上断层 / 俯冲带轴线，你会看到地震几乎只沿着几条窄线走——那不是画上去的，是板块边界自己长出来的形状。

数据来源：美国地质调查局 ANSS 综合地震目录（ComCat），检索 1900-01-01 至 2026-11-07、M≥5.0、西经 180–58°、北纬 14–72°（美国本土 + 阿拉斯加 + 夏威夷 + 波多黎各 + 相邻太平洋 / 大西洋 / 墨西哥 / 加拿大），共 8 032 条，构建期一次性落成本地静态矢量。陆地轮廓：Natural Earth 1:50m land。板块边界：PB2002（Peter Bird, 2003）近似（沙箱无法访问原文件，已用美国及周边主要边界手绘）。合规处理：本图不绘制任何国界与行政区划，只画海陆分界、断层 / 俯冲带轴线和震中；坐标为目录原始 WGS84，不与 GCJ-02 底图混用。口径提示：地震带归属按震中位置与断层轴线距离的近似判据，非官方分区；1964 年以前的记录多来自历史文献回溯测定，定位与震级精度低于现代台网。
