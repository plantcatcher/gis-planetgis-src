南亚次大陆的主体国家，由若干邦与中央直辖区组成，14 亿人口居世界第一，恒河平原与德干高原构成它的地理骨架。点一下地图，看每个邦 / 中央直辖区的中文名、首府、人口、面积与行政区类型。顶栏可在人口 / 面积 / 类型之间切换着色，颜色越深数值越大。

按人口着色：北方邦、马哈拉施特拉与比哈尔等恒河—印度河流域邦人口极密，东北部山区与海岛直辖区则明显稀疏。

数据来源：邦 / 中央直辖区、县边界来自 GADM 4.1（gadm41_IND_shp，WGS84 / EPSG:4326，公开数据）。面积由几何球面实算（约值），行政区类型取自 GADM 的 ENGTYPE 字段，人口 / 首府 / 中文译名为人工整理（约值）。本图仅作行政边界示意，界线画法不代表任何立场。

**制图合规说明**：GADM 原始数据按印度方面的划法，把中印边界西段的阿克赛钦、喀喇昆仑走廊与东段的藏南地区一并计入印度行政区。本站遵循中国法律法规与地图编制规范，已在数据转换阶段按中方主张界线做剔除处理：**藏南地区（印方所谓「阿鲁纳恰尔邦」）整体属于中国领土，本图不作呈现、其面积亦不计入统计**；阿克赛钦与喀喇昆仑走廊归入中国，查谟和克什米尔只保留印方实控部分；GADM 用于标记他国主张版本的重复要素（Z 系列）一并去除。地图界线画法以中方主张为准，正式制图请使用自然资源部标准地图服务提供的官方数据。
