法国行政区划地图

西欧核心国家，13 个本土大区 + 若干海外领地，中央集权与地方大区并存的行政格局。点一下地图，看每个大区 / 海外领地的中文名、首府、人口、面积与行政区类型。顶栏可在人口 / 面积 / 类型之间切换着色，颜色越深数值越大。

按人口着色：法兰西岛（巴黎）一区独大，里昂、马赛等大城市圈次之，西南与中部乡村大区稀疏。

数据来源：大区 / 海外领地、省/市镇边界来自 GADM 4.1（gadm41_FRA_shp，WGS84 / EPSG:4326，公开数据）。面积由几何球面实算（约值），行政区类型取自 GADM 的 ENGTYPE 字段，人口 / 首府 / 中文译名为人工整理（约值）。本图仅作行政边界示意，界线画法不代表任何立场。
