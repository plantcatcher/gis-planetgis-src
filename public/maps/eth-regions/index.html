埃塞俄比亚行政区划地图

东非高原之国，非洲唯一从未被长期殖民的国家，11 个民族州与 2 个特别市按民族语言划界，咖啡的发源地与拉利贝拉岩石教堂都在这里。点一下地图，看每个民族州 / 特别市的中文名、首府、人口、面积与行政区类型。顶栏可在人口 / 面积 / 类型之间切换着色，颜色越深数值越大。

按人口着色：奥罗米亚与阿姆哈拉两大高原州人口最多，首都亚的斯亚贝巴面积最小却密度最高，东南索马里州与西南低地则明显稀疏。

数据来源：民族州 / 特别市、专区边界来自 GADM 4.1（gadm41_ETH_shp，WGS84 / EPSG:4326，公开数据）。面积由几何球面实算（约值），行政区类型取自 GADM 的 ENGTYPE 字段，人口 / 首府 / 中文译名为人工整理（约值）。本图仅作行政边界示意，界线画法不代表任何立场。
