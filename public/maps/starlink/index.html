拖拽旋转这颗 3D 地球，数千颗星链卫星正以真实轨道参数在低地球轨道上运行。它们按 53°、70°、97.6° 三个壳层排成标志性的网格——这就是你在夜空看到的「卫星列车」的来源。拨动下方时间轴，看这个人类史上最大的卫星星座如何从 2019 年的几十颗，长成如今遮天蔽日的巨网。

怎么读这张图

颜色区分壳层：53° 主力（低中纬宽带覆盖）、70° 增强（高纬补盲）、97.6° 极轨（极地太阳同步）。每壳层由若干「轨道面」组成，卫星在面内等距排布、面间错相位——即 Walker 星座，形成格子状网格。点任意卫星可看其壳层、高度、倾角、周期与速度。

为什么这么多

低轨（550km）离地近，信号往返延迟低、单星造价与功耗可控，但单星覆盖面积小——要全球无缝宽带，必须铺几千颗。代价也显而易见：天文光污染（亮卫星划过望远镜视场）、频谱与轨道拥挤，以及最被担心的 凯斯勒级联——碰撞碎片引发更多碰撞，最终让近地轨道不再可用。星链目前约占人类现役卫星总数的一半以上。

数据来源：壳层参数（倾角 / 高度 / 面数）取自公开 Starlink 部署资料（FCC 文件、Jonathan McDowell 卫星数据库）。卫星位置为 Walker 星座模型（非真实 TLE，纯静态、零网络请求），用于呈现结构而非精确定轨。地球昼面贴图来自 NASA / Solar System Scope（自托管）。引擎使用 three.js（MIT）自托管。
