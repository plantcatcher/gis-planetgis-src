# 公众号自动回复规则 · 全球能源与交通三数据包（2026-10-07 新增）

三个数据包：**全球核电机组与核设施分布数据** / **世界港口分布数据** / **全球水电站分布数据**，均为 WGS84 点位 SHP。

## 操作路径

公众号后台 → **自动回复** → **关键词回复** → **添加回复**

每条规则设置：
- **规则名称**：填资料简称（便于自己识别）
- **关键词**：把下方「关键词」逐行填进关键词框，多个词回车分行，命中任意一个都回同一条；匹配方式选 **半匹配（含）**
- **回复类型**：选 **文字**
- **回复内容**：粘贴下方「回复内容」整段
- 保存即可，无需关注条件

> 每个包的 5 个关键词里，最后那个英文词（`GNPT` / `海港shp` / `GloHydroRes`）只是兜底，实际几乎不会有人打，可留可不留。
> 三个包的关键词互不重复，也**不与站内现有 105 条资料的任何关键词冲突**（已全量做过包含关系检测：新增词既不包含、也不被任何已有关键词包含，不会出现「一条消息被两条规则抢」）。

## 红线提醒

- **只给资料页链接，绝不给 R2 裸 zip 直链**（downloads.planetgis.cn/GIS/....zip）。读者必须在资料页输验证码才能下载，这是软门禁的全部意义。
- 资料页 URL **不要带尾斜杠**。
- 验证码大小写不敏感，读者随便打都能过。
- zip 需先上传到 R2 的 `GIS/` 目录且文件名与 slug 完全一致，否则读者拿到验证码也下不了。
