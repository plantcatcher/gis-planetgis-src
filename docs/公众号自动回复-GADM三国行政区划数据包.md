# 公众号自动回复规则 · GADM 三国行政区划数据包（2026-10-08 新增）

三个数据包：**澳大利亚行政区划（6 州 5 领地 + 568 个 LGA）** / **英国行政区划（五级至选区）** / **日本行政区划（47 都道府县 + 1811 市町村）**，均为 GADM 4.1、WGS84 面 SHP。

## 操作路径

公众号后台 → **自动回复** → **关键词回复** → **添加回复**

每条规则设置：
- **规则名称**：填资料简称（便于自己识别）
- **关键词**：把下方「关键词」逐行填进关键词框，多个词回车分行，命中任意一个都回同一条；匹配方式选 **半匹配（含）**
- **回复类型**：选 **文字**
- **回复内容**：粘贴下方「回复内容」整段
- 保存即可，无需关注条件

> 三个包的关键词互不重复，也**不与站内现有 108 条资料的任何关键词冲突**（已全量做过包含关系检测，GADM 三词互不含、也不被已有关键词包含）。
