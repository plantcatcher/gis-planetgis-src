# 公众号自动回复规则 · 城市/规划四书（2026-08-30 新增）

## 操作路径
公众号后台 → **自动回复** → **关键词回复** → **添加回复**

每条规则设置：
- **规则名称**：填书名（便于自己识别）
- **关键词**：填下方「关键词」一列，匹配方式选 **半匹配（含）**
- **回复**：粘贴下方「回复内容」整段
- 保存即可，无需留言/关注条件

> 注意：四本的关键词互不重复，不会冲突。英文 trigger 一并列入作兜底，但读者基本不会打英文，可不填。
