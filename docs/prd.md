# 星球小捕手品牌主站需求文档

## 1. 应用概述

### 1.1 应用名称
星球小捕手品牌主站

### 1.2 应用描述
星球小捕手是一个专业的地理科普频道，内容覆盖公众号、小红书、博客、YouTube等平台，同时开发地理网站小工具、地理安卓软件及个人摄影作品集。本主站作为品牌宣传中心，用于整合展示分布在各子域名的网站与内容，为用户提供统一的入口与浏览体验。

## 2. 核心功能

### 2.1 内容展示板块
主站包含以下核心内容板块：
- 个人介绍
- 作品展示
- 各平台内容汇总
- 网站工具列表
- 各子域名网站链接入口

### 2.2 交互功能
- 点击跳转到各平台
- 展示作品集
- 查看工具列表
- 查看各子域名网站链接

### 2.3 后台内容管理
支持通过后台自行修改以下内容：
- 布局
- 文字
- 图片
- 链接
- 板块顺序
- 增加新的板块

### 2.4 网站声明
- 版权声明
- 隐私政策声明

## 3. 设计要求

### 3.1 视觉风格
- 整体呈现蓝色和绿色，体现地球与地理主题
- 网页画面精美，效果动态顺滑

## 4. 技术要求

### 4.1 部署方式
使用CloudFlare进行部署，不需要服务器

### 4.2 合规要求
网站需包含必要的版权、隐私等声明，满足广告接入的合规要求
