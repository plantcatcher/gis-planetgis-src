## 第一梯队 · 数据全、话题强、骨架可直接复用

### 1. 诺贝尔奖全球分布图
- [ ] 诺贝尔奖全球分布图
- **数据口径**：1901—2026 全部获奖者，按获奖时国籍统计；可分物理/化学/医学/文学/和平/经济六类。
- **数据源**：Nobel Prize 官网（nobelprize.org）开放数据，字段完整（姓名、国籍、年份、奖项、获奖事由）。
- **叙事主线**：欧美占绝对多数 → 20 世纪上半叶德国集中 → 下半叶美国接棒 → 近年亚洲抬头；日本 29 人、中国内地 2 人（莫言、屠呦呦）的对比自带流量。
- **复用点**：时间轴回放、按奖项筛选、榜单弹层（按国/按奖项）、详情面板列获奖者。
- **热度**：★★★★★

### 2. 世界杯历届冠军与参赛版图
- [ ] 世界杯历届冠军与参赛版图
- **数据口径**：1930—2026 共 22 届；三层统计——夺冠次数 / 参赛次数 / 总进球数。
- **数据源**：FIFA 官网或维基百科，历届完整。
- **叙事主线**：巴西 5 冠、意大利德国 4 冠；南美与欧洲的对峙。大洲分色沿用奥斯卡图（南美黄、欧洲蓝、非洲绿、亚洲红）。
- **复用点**：大洲分色、时间轴按届次回放、榜单弹层。
- **热度**：★★★★★（2026 美加墨世界杯刚结束）

### 3. 奥运金牌百年迁移图
- [ ] 奥运金牌百年迁移图
- **数据口径**：1896—2024 累计奖牌（金/银/铜），按国家统计；可加"每届榜首"时间轴。
- **数据源**：Olympedia 完整历史数据。
- **叙事主线**：早期英法主导 → 冷战美苏对抗 → 中国 2000 年后崛起 → 2024 巴黎中美并列。民族情感话题，转发率高。
- **复用点**：时间轴、按奖牌类型切换、榜单弹层。
- **热度**：★★★★★

## 第二梯队 · 垂直话题、长尾流量稳

### 4. 全球大学百强分布图
- [ ] 全球大学百强分布图
- **数据口径**：QS / THE 前 100，按国家统计数量与排名分布。
- **数据源**：排名官网，每年更新一次即可。
- **叙事主线**：美国 30+ 所、英国 15 所、中国 5—7 所；教育焦虑是永恒话题，家长群体转发意愿强。
- **复用点**：国界填色 + 详情面板列该国上榜大学。
- **热度**：★★★★☆

### 5. 福布斯亿万富豪全球分布
- [ ] 福布斯亿万富豪全球分布
- **数据口径**：按国籍统计人数与财富总量；可加行业分类筛选。
- **数据源**：Forbes 实时榜，字段规范。
- **叙事主线**：哪里盛产富豪、财富集中度、行业变迁（科技新贵 vs 传统家族）。
- **复用点**：国界填色 + 榜单 + 详情面板。
- **热度**：★★★★☆

### 6. 全球世界遗产分布图
- [ ] 全球世界遗产分布图
- **数据口径**：UNESCO 世界遗产，按国家统计；分文化遗产 / 自然遗产 / 双重遗产。
- **数据源**：UNESCO 官方开放数据。
- **叙事主线**：中国 59 项、意大利 58 项、德国 54 项，排名接近有竞争感；合规无风险。
- **复用点**：国界填色 + 类型筛选 + 详情面板。
- **热度**：★★★☆☆
